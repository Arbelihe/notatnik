# Notatnik

Lekki edytor plików `.txt` na Androida (8.0+). Bez reklam, bez uprawnień, bez zależności.

- otwieranie plików z dowolnego miejsca (pamięć telefonu, karta SD, Dysk Google)
- „Otwórz za pomocą → Notatnik” w menedżerze plików
- zapis do tego samego pliku albo „Zapisz jako…”
- zachowuje kodowanie (UTF-8, Windows-1250, UTF-16) i końce linii (CRLF/LF), więc pliki z Windowsa zostają zgodne
- pyta przed porzuceniem niezapisanych zmian, nie gubi tekstu przy obrocie ekranu
- jasny i ciemny motyw zgodnie z ustawieniem telefonu

## Pobranie

Najnowszy APK: **Releases → Notatnik.apk** (budowany automatycznie przez GitHub Actions po każdej zmianie).

Instalacja: otwórz pobrany plik na telefonie i zezwól przeglądarce na instalowanie aplikacji z nieznanych źródeł.
